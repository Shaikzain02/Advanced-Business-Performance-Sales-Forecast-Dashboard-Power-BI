# Advanced Business Performance & Sales Forecast Dashboard (Power BI)

## 📊 Project Overview
This project is an **end-to-end Business Intelligence solution** developed using **Power BI** to analyze sales performance, uncover trends, and forecast future sales.  
The dashboard is designed to support **executive-level decision making** as well as **detailed analytical exploration** using clean data modeling and advanced DAX measures.

---

## 🎯 Objectives
- Analyze overall business performance using key sales KPIs
- Understand sales trends across time, categories, products, and regions
- Perform product-level deep-dive analysis
- Forecast future sales using time-series analysis
- Demonstrate industry-standard **star schema data modeling**

---

## 🧱 Data Modeling
- Implemented a **Star Schema** for optimized performance and accurate filtering
- Central **Fact_Sales** table connected to:
  - Dim_Date
  - Dim_Product
  - Dim_Customer
  - Dim_Region
- Single-direction relationships used to avoid ambiguity and improve DAX efficiency

---

## 📌 Dashboard Pages

### 1️⃣ Executive Overview
- Total Sales  
- Total Orders  
- Average Sales per Order  
- Sales trend over time  
- Sales by category  
- Year-based slicer for dynamic filtering  

### 2️⃣ Sales Performance Analysis
- Sales by category and sub-category  
- State-wise sales performance  
- Top products by sales  
- Order volume comparison  

### 3️⃣ Product Deep-Dive Analysis
- Product-level KPIs  
- Sales contribution by category  
- Product ranking based on sales  
- Relationship between sales and order volume  

### 4️⃣ Sales Forecast & Trend Analysis
- Monthly sales trend analysis  
- Month-over-Month (MoM) and Year-over-Year (YoY) comparison  
- 6-month sales forecasting using time-series analytics
